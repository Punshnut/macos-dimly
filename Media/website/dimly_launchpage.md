## Features

### Per-display control that actually behaves

Adjust brightness, blackout, sleep, wake, rename displays, and copy IDs from one place.

### DDC first. Overlay when needed.

Dimly automatically uses true DDC/CI brightness and power controls when available, then falls back without breaking your flow.

### Smart profiles and automation

Save monitor states, reorder profiles, surface smart buttons in Quick Actions, and auto-apply profiles on external display connect.

### Hotkeys that scale with your setup

Use global shortcuts for all externals or target specific displays. Includes a fixed panic shortcut to restore everything instantly.

### Built for daily use

Show display numbers, hide selected displays from the menu list, merge ordering, and run in stealth mode with Dock/menu icon hidden.

### Safe updates and privacy

Sparkle updates with signature verification, notarized builds, no telemetry, no daemons.

## FAQ

### Does Dimly require DDC support?
No. Dimly uses DDC when available and overlay fallback when it is not.

### Can I control each display separately?
Yes. Brightness, blackout, sleep/wake, and naming are all per display.

### Can I automate setups?
Yes. Save profiles and auto-apply a profile when external displays connect.

### Is it private?
Yes. No telemetry, no tracking, no always-on background service.

### Which Macs are supported?
macOS 14+ on both Apple Silicon and Intel.
